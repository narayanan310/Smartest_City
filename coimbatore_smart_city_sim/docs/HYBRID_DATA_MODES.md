# Hybrid data modes and the expanded network

Two scenario axes extend the 1.0 baseline. Both are **toggles in the sidebar**,
under *Data & Calibration Mode*.

| | `simulated` | `hybrid` |
|---|---|---|
| Sidebar label | 🧮 **FABRICATED** — fully generated by this project | 📡 **AUTHENTIC** — gathered data + generated remainder |
| Meaning | every input generated by this project | inputs with a published source are read live from `data/raw/`; the rest stay generated or are explicit assumptions |

Tick **Show data provenance** in the sidebar for a per-input breakdown of what
is authentic, what is generated, and what is an assumption.

---

## 1. What actually changes in hybrid mode

| Input | simulated (fabricated) | hybrid (authentic) |
|---|---|---|
| Solar profile | embedded clear-sky curve, unchanged | curve **scaled** by the NASA monthly deviation for the representative month (April 6.3317/6.20 = 1.021, July 4.0133/3.80 = 1.056) |
| Cell temperature | ambient from IMD normals | NASA monthly mean air temperature (April 28.43 °C, July 24.47 °C) |
| Revenue rate | flat ₹8.70/kWh + surcharge | hourly TNERC ToD tariff + surcharge, realised blend ₹7.07/kWh |
| Emission factor | 0.82 kg CO₂/kWh | 0.727 kg CO₂/kWh (CEA FY2023-24) |
| Diesel counterfactual | ₹19.71/kWh implied fuel value | same (verified TNSTC input, see §4) |

Cloud cover stays synthetic in **both** modes — no weather API is called. The
ecology model is unchanged in both modes; lake benchmarks are cross-checks, not
inputs.

lower than the fabricated one it replaced (₹6.00/₹9.00/₹7.50 versus
₹6.50/₹9.75/₹8.10) even though it generates more.

## 4. Data provenance — what is verified and what is not

### Verified (published source located and read)

| Input | Value | Source |
|---|---|---|
| Solar irradiance, temperature, humidity, wind | GHI 5.45–6.33, T2M 21.61–28.43 °C | **NASA POWER API v2.10.0**, 10.99 N 76.96 E, 2023 monthly — every value re-checked against the live API |
| EV charging ToD tariff | ₹6.00 / ₹9.00 / ₹7.50 | **TNERC Suo-motu Order No. 6 of 2023**, clause 3.1.7 (HT-V, which explicitly covers battery swapping) |
| Grid emission factor | 0.727 (FY2023-24), series back to 2019-20 | **CEA CO₂ Baseline Database v20/v21** |
| Lake area and depth | 1.295 km², 5.82 m | **Gelera-Adefuin (2019) IJITEE v8(6)** |
| Lake water quality | DO 5.71, pH 9.17, BOD 35.7, COD 390, turbidity 11.7 NTU (n=14) | same survey; cross-checked against Nept Journal wetlands paper |
| TNSTC fleet and fuel economy | 2,559 buses (31.10.2025), city ~5.10 KMPL, rural 5.57 | **TNSTC (Coimbatore) RTI handbook**, tn.gov.in; **Times of India, 13 Apr 2022** |
| Electric bus programme | 500 e-buses for Coimbatore/Chennai/Madurai | Government of Tamil Nadu Economic Review 2022-23 |

### Explicit assumptions (no primary source located — editable in the UI)

- 220 km/bus/day duty cycle, 219 kWh/bus/day traction, ₹100.06/litre diesel price
- CAPEX ₹6.5 Cr/MWp, pack ₹25 lakh, hub ₹120 lakh, 8 % discount rate
- Open-access wheeling surcharge ₹0.54/kWh
- Route 45/70 stop naming and the six-point "corridor archetypes" (display only)

### Generated by this project (no real-world counterpart exists)

- The seeded cloud schedule — synthetic in both modes, by design
- The embedded clear-sky diurnal shape (SRRA/MNRE-style, 24 hourly points)
- Half-hourly diurnal solar and dispatch profiles produced by the ingest pipeline
  (planning artefacts; verified for shape, not consumed by the live model)

| Route 70 geometry | 11 points, hand-drawn | **36 OSRM points** | Real road network |

`tests/test_data_authenticity.py` now pins every published value above and fails
if any of the earlier fabricated figures reappears as a data field.

## 6. Data pipeline

```bash
python scripts/ingest_and_vet_data.py   # 92 checks, writes 5 artefacts
```

Vets the three `data/raw/` snapshots and writes `data/processed/` (gitignored by
design; regenerated by a session fixture so a bare clone stays green). The
curated NASA snapshot is committed at
`data/raw/nasa_power_2023_coimbatore.json`, deliberately **not** at
`data/raw/nasa_cache.json` — that path belongs to the runtime auto-cache in
`src/services/nasa_power.py` and the two must never collide.
